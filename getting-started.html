Chrome Extension

Aisera Debug Viewer

Surface real-time debug data from the Aisera platform directly in your browser — no DevTools, no raw network traffic.

Version 1.0.3
Setup

Installation

The extension is distributed as a .zip file and installed manually using Chrome's Developer Mode.

🎬
Animated GIF
Full installation walkthrough — unzip, open chrome://extensions, enable Developer Mode, Load unpacked
1

Unzip the extension

Extract the .zip file to a permanent folder on your computer. Chrome loads the extension directly from this folder — do not move or delete it after installation.

Example: C:\Users\YourName\Extensions\AiseraDebug\ or ~/Extensions/AiseraDebug/
2

Open Chrome Extensions

Navigate to chrome://extensions in your browser, or open the Chrome menu ⋮ → More tools → Extensions.

3

Enable Developer Mode

Toggle Developer mode on in the top-right corner of the Extensions page.

4

Load the extension

Click Load unpacked and select the folder you extracted in Step 1 — the one containing manifest.json.

5

Pin it (optional)

Click the puzzle-piece icon in the Chrome toolbar, find Aisera Debug, and click the pin icon to keep it visible.

Basic Usage

Opening the Debug Panel

Once installed, the extension is always ready on any Aisera page. Here's how to use it:

🎬
Animated GIF
Click Debug button → panel slides in from the right → data appears
1

Navigate to an Aisera page

Go to any URL on login.aisera.cloud. The floating Debug button appears automatically.

2

Trigger a response

Send a chat message, start a flow, or perform any action that triggers an AI or workflow response.

3

Click Debug

The panel slides in from the right. You can also use the keyboard shortcut Ctrl+D (configurable in Settings).

You can drag the Debug button anywhere on screen if it's in the way.
✅

The panel updates automatically as new responses come in. You do not need to close and reopen it.

The Panel

Tabs

The panel has six tabs. Use Ctrl+[ and Ctrl+] to cycle between them (shortcuts are configurable).

Dashboard

Your personalized summary

Pin any value from the Debug or Flow Debug tab to create a persistent summary view. Pinned cards survive page reloads and browser sessions.

  • Drag the ⠿ handle to reorder cards
  • Remove individual cards with ×, or use Deselect All to clear everything
  • Each field within a card is individually collapsible
🎬
Animated GIF
Pinning a card from the Debug tab → it appears on the Dashboard
Errors

Automatic error detection

Automatically scans the full response payload for error indicators — null values, empty strings, failure status codes, and warning flags.

  • Each card shows the field name, a breadcrumb path to its location in the JSON, and (for flow nodes) the node label
  • Click → Debug to jump to the relevant card in the Debug or Flow Debug tab and highlight it in red
  • If no issues are found, the tab shows a green checkmark
🎬
Animated GIF
Errors tab with cards → clicking → Debug jumps and highlights the relevant node card
Debug

Structured data view

Displays the AI Lens debug payload as expandable/collapsible cards. Values are color-coded by type. Long fields auto-collapse with a preview.

  • Use the checkboxes to pin cards to the Dashboard
  • Select All / Deselect All controls all pins at once
  • Click the { } button on any node to open a data panel with copyable JSON
Flow Debug

Workflow node execution

Shows each workflow node as a collapsible card with Input, Output, Conditions, Node ID, and Execution Time. Subflows are indented hierarchically.

  • A status badge at the top shows overall flow execution status
  • Nodes with errors are flagged in red at the top of their card
  • Click { } to open the full data panel for any node
🎬
Animated GIF
Scrolling through node cards, expanding a subflow, opening a data panel
Raw JSON

Full unfiltered payload

The complete, unmodified API response as an interactive collapsible JSON tree. Use this when you need to inspect the full payload without any filtering. Click Copy JSON to copy the raw text.

Settings

Persistent preferences

All settings are stored across sessions. Changes take effect immediately — no reload required.

Settings Deep Dive

Flow Debug Sections

The Flow Debug tab shows different content depending on whether you're on the AI Lens page or a workflow-details page. Settings gives you two independent lists — one per page type — so you can control exactly which sections appear and in what order for each context.

🎬
Animated GIF
Reordering and toggling sections in the AI Lens list vs. the Workflow Details list
💡

Sections that are enabled but absent or empty in the current response appear at the bottom of the Flow Debug tab with a status badge — empty or not in response.

Pinning to the Dashboard

Every card in the Debug and Flow Debug tabs can be pinned to the Dashboard using the checkbox in its top-right corner — including Executed Functions, LLM Calls, and Durations on the AI Lens page.

🎬

Jumping from Errors to Debug

Each card in the Errors tab has a → Debug button. Clicking it switches to the Debug or Flow Debug tab, scrolls to the relevant card, and briefly highlights it with a red glow so you can find it instantly.

Tips

Tips & Tricks

🖱️

The Debug button can be dragged anywhere on screen. Its position is remembered across sessions.

🔄

Data updates automatically while the panel is open. You don't need to reopen the panel after each action.

📌

Pinned dashboard cards survive page reloads. The paths are stored in Chrome's local extension storage, not the page.

🔗

Click any field key label inside a card to collapse or expand that individual field.

{ }

The { } button on any node card opens a data panel with the full JSON for that node — including a Copy button that expands any nested JSON strings automatically.

🔢

The workflow test counter at the bottom of Settings tracks how many times you've clicked OK in the Test Flow modal. Reset it any time.
